# Third-Party Assets

## Standard Tarot Images

The bundled Standard Tarot card images are Rider-Waite-Smith tarot images derived from the public-domain deck illustrated by Pamela Colman Smith.

Local asset path:

`app/src/main/assets/seed/tarot/rws1909/`

Source used for the bundled files:

<https://github.com/searge/tarot/tree/master/assets/img/big>

The image folder in that repository includes an Unlicense/public-domain dedication:

<https://github.com/searge/tarot/blob/master/assets/img/LICENSE>

Additional public-domain licensing context for the Rider-Waite-Smith deck is available from Wikimedia Commons:

<https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck>

Keep this deck as a default editable starter deck. Do not replace it with modern recolored Rider-Waite editions unless their license is explicitly compatible with free/open-source redistribution.
